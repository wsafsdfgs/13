软著名：基于 Vue 的物业小区报修工单调度系统
开发的硬件环境：独立显卡，8GB内存，256GB硬盘空间
运行的硬件环境：3.3GHz处理器，4GB内存，256GB硬盘空间
开发该软件的操作系统：Windows 10家庭版
软件开发环境 / 开发工具：Visual Studio Code，Node.js，jquery.js框架
该软件的运行平台 / 操作系统：谷歌浏览器，Edge浏览器，Windows 10家庭版
软件运行支撑环境 / 支持软件：Node.js开发环境，nginx运行环境，npm包管理器
编程语言：JavaScript，HTML
源程序量：2724
开发目的：访问网站可以填写房屋故障相关内容，提交报修相关申请，查看名下工单的流转进度。操作人员可以调取各类报修单据，分配对应处理任务，登记现场处置情况。
面向领域：电子信息领域
软件的主要功能：这是一款面向小区物业工单处理的线上服务平台。该项目搭建网页端操作渠道，提供报修内容登记、工单流转处理的相关服务，也搭配人员排班、问题记录的相关操作内容。相关人员还能查看过往留存的报修记录，核对不同时段的工单内容，完成日常事务对接，同步现场处理的相关信息，完成小区日常运维相关的各项操作。
软件的技术特点：APP,网页软件，是一个跨平台的网页应用，基于jquery.js框架实现核心逻辑，结合HTML和bootstrap进行界面设计，确保在Windows、Linux、和Mac操作系统上均可流畅运行。
