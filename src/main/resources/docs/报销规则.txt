
# 报销规则

## 报销范围
1. 差旅费：
   - 交通费：飞机票、火车票、汽车票等
   - 住宿费：标准内酒店住宿
   - 餐饮费：每日标准限额
   - 市内交通费：出租车票、公共交通凭证

2. 办公费：
   - 办公用品采购
   - 文具、打印、复印等
   - 订阅费：专业书籍、期刊等

3. 业务招待费：
   - 客户接待餐费
   - 会议招待费
   - 礼品费（需符合公司规定）

## 报销流程
1. 发票收集：
   - 确保发票真实有效
   - 发票抬头为公司全称
   - 发票内容与实际业务相符

2. 填写报销单：
   - 登录OA系统填写《费用报销单》
   - 上传发票扫描件或照片
   - 填写费用明细和用途

3. 审批流程：
   - 员工填写 → 部门主管审批 → 财务审核 → 出纳付款
   - 金额5000元以下：部门主管审批
   - 金额5000-20000元：部门主管+财务经理审批
   - 金额20000元以上：部门主管+财务经理+总经理审批

4. 报销时限：
   - 费用发生后一个月内提交报销申请
   - 超期需特别说明，经总经理批准后方可报销

## 报销规定
1. 报销标准：
   - 住宿：一线城市不超过500元/天，二线城市不超过400元/天
   - 餐饮：商务招待不超过300元/人/餐
   - 市内交通：实报实需，但需注明用途

2. 注意事项：
   - 发票需在有效期内
   - 不可报销与工作无关的费用
   - 严禁虚报、冒领报销费用
   - 报销材料需保存至少3年备查

3. 特殊情况：
   - 超标准报销需提前申请，获批后方可执行
   - 紧急情况可先电话沟通，事后补办手续
