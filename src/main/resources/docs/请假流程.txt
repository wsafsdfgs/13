
# 请假流程

## 请假类型
1. 病假：因身体不适需要治疗或休息的请假。
2. 事假：因个人事务需要处理的请假。
3. 年假：根据工龄享受的带薪假期。
4. 婚假：员工结婚享受的假期。
5. 产假：女员工生育享受的假期。
6. 丧假：直系亲属去世的假期。

## 请假申请流程
1. 提前申请：
   - 病假/事假：提前3天提交申请
   - 年假：提前一周提交申请
   - 婚假/产假/丧假：提前两周提交申请

2. 提交申请：
   - 登录OA系统填写《请假申请表》
   - 上传相关证明材料（如医院证明等）
   - 选择请假类型和起止时间

3. 审批流程：
   - 1-3天：部门主管审批
   - 3-7天：部门主管+部门总监审批
   - 7天以上：部门主管+部门总监+HR审批

4. 获批后：
   - 系统发送通知确认
   - 工作交接安排
   - 请假期间保持联系方式畅通

## 特殊情况处理
1. 突发疾病等紧急情况，可先电话通知直属主管，事后24小时内补办手续。
2. 请假期间如需延长，需提前联系直属主管申请，获批后方可延长。
3. 未按流程请假或未经批准擅自离岗，按旷工处理。
